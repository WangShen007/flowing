# Visual specification
Canvas 1600 × 770, white background. Chinese labels; Arial with system CJK fallback.
Three semantic regions: evidence (blue), human-controlled write (warm coral), results (teal).
Typography: title 32, stage headings 26, node labels 23, annotations 19.
Node radius 12px; strokes 1.5px; arrows 2px dark slate, filled arrowheads.
Main baseline y=280; write branch y=460; terminal and optional memory y=640.
No raster artwork, shadows, gradients or decorative token blocks.
Canvas is tuned to README width rather than literal manuscript column sizing.
